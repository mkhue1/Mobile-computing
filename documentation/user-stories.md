# MVP User Stories

## Epic 1: Session Management

| ID | User Story |
|---|---|
| US-01 | As a gamer, I want to create a gaming session with a game, time and player limit so that I can organise a session easily. |
| US-02 | As a gamer, I want to search for and select a game so that I can organise sessions for both popular and obscure games. |
| US-03 | As a gamer, I want to invite specific friends or groups so that I can quickly organise sessions with the right people. |
| US-04 | As a gamer, I want to create an open lobby so that eligible players can join without a direct invitation. |
| US-05 | As a gamer, I want to accept, decline, join or leave a session so that I can manage my participation. |
| US-06 | As a session organiser, I want to view participants and edit or cancel my session so that I can manage changes. |
| US-07 | As a gamer, I want to set a session as online or in person so that participants know how the session will be played. |
| US-08 | As a session organiser, I want to specify a location for an in-person session so that participants know where to attend. |
| US-09 | As a session organiser, I want the lobby to close when the player limit is reached so that the session cannot become overfilled. |
| US-10 | As a session organiser, I want to share a session invitation using NFC so that nearby users can quickly view and join my session. |
| US-11 | As a session organiser, I want to choose who can see and join my session so that I can control whether it is private, group-only, friends-only or open. |
| US-12 | As a session organiser, I want to add notes to a session so that participants know any extra details or requirements. |
| US-13 | As a gamer, I want to view the full details of a gaming session so that I can decide whether and how to participate. |
| US-14 | As a gamer, I want to view and respond to my pending session invitations so that I can manage upcoming invitations easily. |

## Epic 2: Calendar & Scheduling

| ID | User Story |
|---|---|
| US-15 | As a gamer, I want to see my gaming sessions in a calendar so that I can manage my schedule. |
| US-16 | As a gamer, I want to import my phone calendar so that existing commitments can block unavailable times. |
| US-17 | As a gamer, I want to be warned when a session conflicts with my existing calendar so that I can avoid double-booking myself. |
| US-18 | As a gamer, I want to receive reminders and notifications about upcoming or changed sessions so that I stay informed. |

## Epic 3: Friends & Groups

| ID | User Story |
|---|---|
| US-19 | As a gamer, I want to add, remove and manage friends so that I can control who I play with. |
| US-20 | As a gamer, I want to create and manage friend groups so that I can organise recurring groups more easily. |
| US-21 | As a gamer, I want to add another user using NFC so that we can quickly connect in person. |
| US-22 | As a gamer, I want to add another user by scanning their QR code so that I can connect without searching manually. |
| US-23 | As a gamer, I want to accept or decline friend requests so that I can control who is added to my friends list. |

## Epic 4: QR Invitations & Security

| ID | User Story |
|---|---|
| US-24 | As a session organiser, I want to generate a QR invitation so that others can quickly access my session. |
| US-25 | As a gamer, I want to scan a session QR code so that I can quickly view and join the session. |
| US-26 | As a gamer, I want to unlock the app using biometric authentication so that my account remains secure. |

## Epic 5: Local Event Discovery

| ID | User Story |
|---|---|
| US-27 | As a gamer, I want to discover and view nearby gaming events on a map so that I can find local activities. |
| US-28 | As a gamer, I want to sign up for a local gaming event so that I can confirm my attendance. |

## Epic 6: Account & Onboarding

| ID | User Story |
|---|---|
| US-29 | As a new user, I want to create an account and set up a basic profile so that I can use the app and connect with other gamers. |
