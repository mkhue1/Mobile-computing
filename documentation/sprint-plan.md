# Sprint Plan

## Overview

The project will be delivered across three sprints.

## Sprint 1: Core App, Sessions & Gaming Calendar

### Goal

Deliver the core end-to-end experience so that users can create accounts, manage friends, create gaming sessions, invite others, manage participation, and view their gaming commitments in the app calendar.

### User Stories

- **US-01** Create a gaming session with a game, time and player limit.
- **US-02** Search for and select a game.
- **US-03** Invite specific friends or groups.
- **US-05** Accept, decline, join or leave a session.
- **US-06** View participants and edit or cancel a session.
- **US-07** Set a session as online or in person.
- **US-08** Specify a location for an in-person session.
- **US-12** Add notes to a session.
- **US-13** View the full details of a gaming session.
- **US-14** View and respond to pending session invitations.
- **US-15** View gaming sessions on the app calendar.
- **US-19** Add, remove and manage friends.
- **US-23** Accept or decline friend requests.
- **US-29** Create an account and set up a basic profile.

## Sprint 2: Social Features, Sensors & Smart Scheduling

### Goal

Add the social and sensor-based functionality, including NFC, QR codes, biometric authentication, open lobbies, friend groups, external calendar integration and scheduling awareness.

### User Stories

- **US-04** Create an open lobby.
- **US-09** Automatically close a lobby when the player limit is reached.
- **US-10** Share a session invitation using NFC.
- **US-11** Choose who can see and join a session.
- **US-16** Import a phone calendar.
- **US-17** Receive warnings when a gaming session conflicts with an existing calendar event.
- **US-18** Receive reminders and notifications for upcoming or changed sessions.
- **US-20** Create and manage friend groups.
- **US-21** Add another user using NFC.
- **US-22** Add another user by scanning their QR code.
- **US-24** Generate a QR invitation for a gaming session.
- **US-25** Scan a session QR code to view and join a session.
- **US-26** Unlock the application using biometric authentication.

## Sprint 3: Local Discovery & Final Integration

### Goal

Add location-based event discovery and complete integration and refinement of the application's core scheduling, social and sensor features.

### User Stories

- **US-27** Discover and view nearby gaming events on a map.
- **US-28** Sign up for a local gaming event.

### Additional Focus

- Integrate local events with the app calendar.
- Resolve remaining integration issues.
- Improve UI consistency and responsiveness.
- Prepare screenshots, report material and the final video demonstration.
